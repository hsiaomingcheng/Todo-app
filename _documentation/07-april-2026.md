You learned how to structure an app where a login token and a `logout()` function can be easily accessed from any file (like your Navigation Bar) without having to pass it down manually through every component.

### 2. Intercepting & Controlling Navigation Flow
- By developing your `ProtectedRoute`, you learned standard industry patterns for UI security: wrapping sensitive application code underneath a protective wrapper that queries existing state and denies unauthorized access before anything renders visually.

### 3. Relational vs. Flat Database Designs
- You learned why flat database tables (like just users mapping straight to tasks) limit scale, and you practiced how to conceptualize and map out hierarchical, multi-tiered relationships. You learned that tasks are actually features inside `cards`, cards live in `lists`, and lists live in `boards`, which themselves belong to `users` via the many-to-many `board_members` table!

### 4. Scaling Backend API Routes in FastAPI
- You learned how to break apart monolithic applications by splitting the API into separate modular chunks (`auth.py`, `task.py`, `board.py`) and plugging them efficiently into a central `router.py`. You also saw the strength of using `Depends()` blocks alongside your API routes to authorize queries implicitly based on the `current_user`.
